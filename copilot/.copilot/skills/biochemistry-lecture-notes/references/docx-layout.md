# Approved DOCX Layout

Use `python-docx` or an equivalent programmatic Word workflow so formatting is
consistent and repeatable.

## Page and Typography

- Page size: A4
- Approximate margins:
  - top: 1.8 cm
  - bottom: 1.7 cm
  - left: 1.9 cm
  - right: 1.75 cm
- Body font: Aptos 10.5–10.7 pt; Calibri or Arial is an acceptable fallback.
- Body line spacing: approximately 1.08–1.15.
- Use restrained paragraph spacing and avoid walls of text.
- Keep headings with the following paragraph and prevent table rows from
  splitting when practical.

## Colour Palette

Use one restrained academic palette:

| Role | Colour |
|---|---|
| Main heading / dark accent | `#173B4D` |
| Secondary accent | `#2B7A78` |
| Tertiary / warm accent | `#C98B2E` |
| Pale teal fill | `#EAF4F3` |
| Pale warm fill | `#FBF4E7` |
| Main text | `#202B33` |
| Muted text | `#5C6970` |

## Heading Scale

- Document title: about 24–26 pt
- Part / Heading 1: about 16–18 pt
- Heading 2: about 13–14 pt
- Heading 3: about 11–12 pt
- Figure captions: about 8.5–9 pt, centred and italic

## Student Notes

Use a dedicated cover page containing:

- document type;
- unit title and subtitle;
- course title and code;
- programme and semester;
- contact hours;
- plain-language unit outcome.

Use page breaks before major parts, end-of-unit questions, and references.
Use a restrained header and footer after the cover, including course code and
page number.

## Tables

- Use dark-teal header cells with white text.
- Use pale alternating row shading where it improves scanning.
- Keep most tables to four columns or fewer in portrait orientation.
- Split an oversized comparison table into two smaller tables instead of using
  unreadably narrow columns.
- Use approximately 8.3–9 pt table text.
- Repeat header rows across pages when supported.

## Assessments

- Quiz and surprise-test documents should use a compact first-page header rather
  than wasting a full cover page.
- Show course, programme, marks, and suggested time in a compact table.
- Teacher key may use a full cover page and should include an assessment
  blueprint.

## Figures

- Generate original schematics at high resolution, normally around 1600–1800 px
  wide.
- Use simple labels, generous whitespace, and the approved palette.
- Insert at an appropriate width for A4 portrait and provide a caption.
- Avoid more than one complex idea per figure.

## Filenames

Use Roman numerals to match the syllabus:

```text
Unit II - Student Notes.docx
Unit II - Teacher Key.docx
Unit II - Quiz.docx
Unit II - Surprise Test.docx
```
